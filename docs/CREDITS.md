# 3D model credits and licences

The scooter, bicycle, riders, restaurant staff, pedestrians and the dispatcher portrait in `web/public/models/` and `web/public/img/` are generated by `tools/models/build_models.py` (Blender 5.2 as a Python module).

## Vehicles

The yellow classic scooter and the black city bicycle with a front basket were modelled for this project in code (`tools/models/vehicles.py`). They imitate the general look of a vintage scooter and a roadster bicycle. They copy no brand, logo or third-party model.

## People

The people are built from the open MakeHuman data set: the base body mesh, the shape targets, the skins, the clothes, hair, eyes, eyebrows and eyelashes. The data come from the `makehuman-data-v1` npm package. That package is only downloaded on the build machine and is **not** included in this repository.

The generator adds these on top of the data:
- the poses
- the texture edits (recolouring, removing the MakeHuman logo from the shirts)
- the motorcycle helmet, cap, shemagh and agal
- the foil trays and pizza boxes

**About the MakeHuman licence.** The asset metadata refers to MakeHuman's licence exception for exported models (makehuman.org, "external tools license"). Under that exception, models generated from the MakeHuman mesh may be used in other products. The MakeHuman 1.1 releases describe their bundled assets as CC0.

The models here were generated by this project's own script, not exported from the MakeHuman application. **Before a commercial launch, have the licence position reviewed.** If there is any doubt, the people can be regenerated from assets you have licensed yourself, using the same script.

The CC BY assets above must stay credited, for example in the game's "About" screen or in store listings.

`web/public/models/models.json` lists every asset each model file was built from, with triangle counts and file sizes.

## Regenerating

```bash
python3.13 -m venv .venv-models
.venv-models/bin/pip install bpy==5.2.2 numpy scikit-image opencv-python-headless pillow
npm pack makehuman-data-v1 && mkdir -p .mh && tar xzf makehuman-data-v1-*.tgz -C .mh
MH_DATA=$PWD/.mh/package/public/data .venv-models/bin/python tools/models/build_models.py --preview /tmp/previews
```
